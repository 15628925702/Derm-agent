[Skill System Design]

Definition:

Skill = One atomic clinical reasoning action.

Constraints:

- Must NOT output final disease
- Must output structured evidence
- Must be interpretable

Skill Categories:

1. Observation Skills
2. Pattern Skills
3. Reasoning Skills
4. Risk/Uncertainty Skills
5. Specialist Skills (limited)

Execution:

Each skill:
  input: CaseState
  output: structured dict

All outputs stored in:
  state.skill_outputs[skill_name]
