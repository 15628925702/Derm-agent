[System Principles - MUST FOLLOW]

1. Qwen is the ONLY final decision maker.
   - Agent must NEVER output final diagnosis label.
   - Agent must NOT override Qwen.

2. Agent is an enhancement layer, not a classifier.
   - No voting system.
   - No scoring-based classification.

3. Skills represent clinical reasoning actions.
   - NOT disease predictors.
   - NOT label classifiers.

4. Experience is structured reasoning knowledge.
   - NOT raw data storage.

5. Cognition represents self-awareness.
   - Tracks system strengths, weaknesses, biases.

6. All modules must communicate via evidence_package.

7. System must NEVER degrade Qwen baseline performance.

If any implementation violates above rules → INVALID.
