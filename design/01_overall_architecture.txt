[Overall Architecture]

Pipeline:

Input Case
  ↓
Qwen Initial Perception
  ↓
Agent Enhancement Layer
  ├── Skill System
  ├── Experience System
  ├── Cognition System
  ↓
Evidence Package
  ↓
Qwen Final Diagnosis
  ↓
Reflection
  ↓
Write-back (Experience + Cognition)

Key Design:

- Agent does NOT diagnose.
- Agent provides structured reasoning evidence.
- Qwen integrates all evidence.

Core Interface:

run_agent(case_input) → evidence_package
