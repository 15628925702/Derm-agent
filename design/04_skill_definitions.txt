[Detailed Clinical Skill Definitions]

--------------------------------
Skill 1: morphology_analysis_skill
--------------------------------

Purpose:
Extract primary lesion morphology.

Doctor Thinking:
"What type of lesion is this?"

Output:
- lesion_type: macule / papule / plaque / nodule
- size_range
- elevation
- count

--------------------------------
Skill 2: color_pattern_analysis_skill
--------------------------------

Purpose:
Analyze pigmentation patterns.

Doctor Thinking:
"Is color uniform? multi-color? suspicious?"

Output:
- primary_color
- color_variation
- pigmentation_pattern
- asymmetry_color

--------------------------------
Skill 3: border_surface_analysis_skill
--------------------------------

Purpose:
Assess boundary and surface.

Doctor Thinking:
"Is border clear? irregular? surface smooth?"

Output:
- border_clarity
- border_irregularity
- surface_texture
- scaling_presence

--------------------------------
Skill 4: distribution_analysis_skill
--------------------------------

Purpose:
Analyze lesion distribution.

Doctor Thinking:
"Where and how are lesions distributed?"

Output:
- body_location
- symmetry
- localized_vs_generalized
- clustering_pattern

--------------------------------
Skill 5: temporal_evolution_skill
--------------------------------

Purpose:
Understand progression.

Doctor Thinking:
"How did it evolve over time?"

Output:
- onset_type (acute/chronic)
- progression_speed
- recurrence
- stability

--------------------------------
Skill 6: metadata_consistency_skill
--------------------------------

Purpose:
Check consistency between image and metadata.

Doctor Thinking:
"Does image match patient info?"

Output:
- consistency_score
- conflicts
- suspicious_points

--------------------------------
Skill 7: differential_compare_skill
--------------------------------

Purpose:
Compare top candidates.

Doctor Thinking:
"What features support A vs B?"

Output:
- candidate_pairs
- supporting_evidence
- conflicting_evidence

--------------------------------
Skill 8: contradiction_check_skill
--------------------------------

Purpose:
Detect reasoning inconsistencies.

Doctor Thinking:
"What doesn't make sense?"

Output:
- contradictions
- missing_links
- reasoning_gaps

--------------------------------
Skill 9: malignancy_risk_assessment_skill
--------------------------------

Purpose:
Assess malignant risk.

Doctor Thinking:
"Is this dangerous?"

Output:
- risk_level (low/medium/high)
- risk_evidence
- alarm_signals

--------------------------------
Skill 10: uncertainty_assessment_skill
--------------------------------

Purpose:
Quantify uncertainty.

Doctor Thinking:
"How confident am I?"

Output:
- uncertainty_level
- reasons
- missing_information

--------------------------------
Skill 11: mel_nev_specialist_skill
--------------------------------

Purpose:
Handle MEL vs NEV confusion.

Output:
- differentiation_features
- decision_hint
- confidence

--------------------------------
Skill 12: ack_scc_specialist_skill
--------------------------------

Purpose:
Handle ACK vs SCC confusion.

Output:
- keratinization_features
- malignancy_clues
- recommendation

--------------------------------
Skill 13: lesion_description_structuring_skill
--------------------------------

Purpose:
Organize image and metadata into a standard dermatologist-style lesion description.

Doctor Thinking:
"How would I restate this lesion in standard clinical description language before reasoning further?"

Output:
- primary_lesion_morphology
- color
- border
- surface
- size_count
- distribution
- associated_context

--------------------------------
Skill 14: exclusion_reasoning_skill
--------------------------------

Purpose:
Perform exclusion-style reasoning over current candidates.

Doctor Thinking:
"Which active candidates are less likely, what argues against them, and what evidence is still missing before I can exclude them strongly?"

Output:
- unlikely_candidates
- exclusion_evidence
- required_missing_evidence
- exclusion_confidence

--------------------------------
Skill 15: information_gap_detection_skill
--------------------------------

Purpose:
Identify what clinically meaningful information is still missing.

Doctor Thinking:
"What information do I still need, why does it matter, and how much uncertainty remains if I do not get it?"

Output:
- missing_information
- why_it_matters
- impact_on_differential
- uncertainty_if_missing

--------------------------------
Skill 16: escalation_recommendation_skill
--------------------------------

Purpose:
Identify whether more cautious diagnostic checking is needed.

Doctor Thinking:
"Given current risk, conflict, and uncertainty, do I need to escalate checking or be more cautious?"

Output:
- whether_escalation_needed
- escalation_reason
- suggested_next_check_type
- caution_flags
