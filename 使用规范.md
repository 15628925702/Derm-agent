# DermAgent 使用规范

## 线路说明

三条数据线路，每条有专用经验库和专用 policy，通过环境变量切换。
所有线路均使用手工规则（heuristic），三个参数化组件全部关闭：
- controller_family: heuristic
- enable_learned_retrieval_reranker: false
- enable_evidence_calibrator: false

| 线路 | 数据集 | 经验库 bootstrap case 数 | tactical 数 |
|------|--------|------------------------|------------|
| PAD-UFES-20 | pad_ufes_20 | 174 | 2966 |
| ISIC2019 | isic2019 | 24 | 286 |
| HAM10000 | ham10000 | 24 | 277 |

---

## 切换线路

```bash
# PAD-UFES-20（默认，不需要 source）
cd /root/DermAgent

# ISIC2019
cd /root/DermAgent && source state/dataset_adaptation/isic2019_v1/experiment.env

# HAM10000 v2
cd /root/DermAgent && source state/dataset_adaptation/ham10000_v2/experiment.env
```

---

## 跑评测（30 case，手工规则，专用经验库）

### 方式一：前台跑（实时看进度，终端被占用）

**PAD-UFES-20**
```bash
cd /root/DermAgent && python3 scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data \
  --limit 30 --seed 0 --data-split test \
  --split-json /root/DermAgent/outputs/pad_ufes_20_split.json \
  --output-dir /root/DermAgent/outputs/compare_test_30_heuristic
```

**ISIC2019**
```bash
cd /root/DermAgent && source state/dataset_adaptation/isic2019_v1/experiment.env && python3 scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data \
  --limit 30 --seed 0 --data-split test \
  --split-json /root/DermAgent/outputs/dataset_adaptation/isic2019_v1/isic2019_split.json \
  --output-dir /root/DermAgent/outputs/dataset_adaptation/isic2019_v1/compare_test_30_heuristic_v3
```

**HAM10000 v2**
```bash
cd /root/DermAgent && source state/dataset_adaptation/ham10000_v2/experiment.env && python3 scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data \
  --limit 30 --seed 0 --data-split test \
  --split-json /root/DermAgent/outputs/dataset_adaptation/ham10000_v2/ham10000_split.json \

```

### 方式二：后台跑 + 实时查进度（tee 同时输出到终端和日志）

**PAD-UFES-20**
```bash
cd /root/DermAgent && python3 scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data \
  --limit 30 --seed 0 --data-split test \
  --split-json /root/DermAgent/outputs/pad_ufes_20_split.json \
  --output-dir /root/DermAgent/outputs/compare_test_30_heuristic \
  2>&1 | tee /tmp/pad30_heuristic.log &
```

**ISIC2019**
```bash
cd /root/DermAgent && source state/dataset_adaptation/isic2019_v1/experiment.env && python3 scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data \
  --limit 30 --seed 0 --data-split test \
  --split-json /root/DermAgent/outputs/dataset_adaptation/isic2019_v1/isic2019_split.json \
  --output-dir /root/DermAgent/outputs/dataset_adaptation/isic2019_v1/compare_test_30_heuristic_v3 \
  2>&1 | tee /tmp/isic30_heuristic_v3.log &
```

**HAM10000 v2**
```bash
cd /root/DermAgent && source state/dataset_adaptation/ham10000_v2/experiment.env && python3 scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data \
  --limit 30 --seed 0 --data-split test \

  --output-dir /root/DermAgent/outputs/dataset_adaptation/ham10000_v2/compare_test_30_heuristic \
  2>&1 | tee /tmp/ham30_heuristic.log &
```

查进度（方式二用）：
