# DermAgent 使用规范

## 目标

当前仓库支持三条数据集线路分别使用各自的：

- `policy_root`
- `split_state_root`
- 经验库
- 输出目录

运行评测时，必须切换到对应的数据集分仓，不能混用。

当前推荐运行方式默认走手工规则（heuristic-only）：

- `controller_family = heuristic`
- `enable_learned_retrieval_reranker = false`
- `calibrator_mode = heuristic`

说明：

- `PAD-UFES-20` 目前使用默认主仓 `/root/DermAgent/state/policy` 和 `/root/DermAgent/state/split_states`
- `HAM10000` 使用 `ham10000_v2`
- `ISIC2019` 使用 `isic2019_v1`

## 数据集分仓

### PAD-UFES-20

- 数据根：`/root/DermAgent/data/pad_ufes_20`
- policy root：`/root/DermAgent/state/policy`
- split state root：`/root/DermAgent/state/split_states`
- 推荐 split json：`/root/DermAgent/outputs/overnight_eval_bundle/split_sanity.json`

切换方式：

```bash
cd /root/DermAgent
export DERMAGENT_POLICY_ROOT=/root/DermAgent/state/policy
export DERMAGENT_SPLIT_STATE_ROOT=/root/DermAgent/state/split_states
```

### HAM10000

- 数据根：`/root/DermAgent/data/ham10000`
- policy root：`/root/DermAgent/state/dataset_adaptation/ham10000_v2/policy`
- split state root：`/root/DermAgent/state/dataset_adaptation/ham10000_v2/split_states`
- 推荐 split json：`/root/DermAgent/outputs/dataset_adaptation/ham10000_v2/ham10000_split.json`

切换方式：

```bash
cd /root/DermAgent
source /root/DermAgent/state/dataset_adaptation/ham10000_v2/experiment.env
```

### ISIC2019

- 数据根：`/root/DermAgent/data/isic2019`
- policy root：`/root/DermAgent/state/dataset_adaptation/isic2019_v1/policy`
- split state root：`/root/DermAgent/state/dataset_adaptation/isic2019_v1/split_states`
- 推荐 split json：`/root/DermAgent/outputs/dataset_adaptation/isic2019_v1/isic2019_split.json`

切换方式：

```bash
cd /root/DermAgent
source /root/DermAgent/state/dataset_adaptation/isic2019_v1/experiment.env
```

## 运行前检查

### 1. 进入仓库

```bash
cd /root/DermAgent
```

### 2. 确认 Qwen 服务已启动

```bash
curl -sS -H "Authorization: Bearer EMPTY" http://127.0.0.1:8000/v1/models
```

### 3. 不要混仓

不要在一个 shell 里：

- 先 `source` HAM10000
- 再直接跑 ISIC2019

换数据集前，重新执行对应的切换命令。

## 跑评测

下面所有命令都是：

- direct Qwen baseline vs agent + Qwen
- 冻结评测
- 使用对应数据集的专用经验库

python scripts/compare_agent_vs_qwen.py \
  --data-root /root/DermAgent/data/pad_ufes_20 \
  --limit 12 \
  --data-split test \

## 结果文件位置

每次运行后，终端会输出三个关键路径：

- `report_path`
- `evaluation_manifest_path`
- `result_manifest_path`

通常最有用的是：

```bash
cat <report_path>
```

或者：

```bash
cat <result_manifest_path>
```

## 常见错误

### 1. `unrecognized arguments` / `bash: --data-split: 未找到命令`

原因：

- 命令里的续行反斜杠 `\` 后面有空格

错误示例：

```bash
--limit 12 \ 
```

正确写法：

```bash
--limit 12 \
```

或者直接使用一行版命令。

### 2. `Metadata CSV not found`

PAD-UFES-20 这条线必须显式传：

```bash
--split-json /root/DermAgent/outputs/overnight_eval_bundle/split_sanity.json
```

不要裸跑默认 split。

### 3. 结果写到别的数据集目录

原因：

- 没有切换对应的 `DERMAGENT_POLICY_ROOT`
- 没有切换对应的 `DERMAGENT_SPLIT_STATE_ROOT`

跑之前先确认：

```bash
echo $DERMAGENT_POLICY_ROOT
echo $DERMAGENT_SPLIT_STATE_ROOT
```

## 推荐顺序

如果要连续跑三条线，推荐顺序：

1. `PAD-UFES-20`
2. `HAM10000`
3. `ISIC2019`

每换一条线，都重新执行该数据集对应的切换命令。
