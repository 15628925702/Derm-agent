# DermAgent 项目索引

这份索引放在仓库根目录，和 `README.md` 同级，用来说明当前整理后的目录分工。以后找文档、实验入口、旧资料，优先从这里进入。

## 顶层常用入口

| 路径 | 用途 | 备注 |
|---|---|---|
| `README.md` | 项目主说明 | 保留原始入口。 |
| `项目索引.md` | 当前这份目录导航 | 中文索引，说明整理后的结构。 |
| `6x6工作流状态_20260506.md` | 6 模型 x 6 数据集 workflow 调参地图 | 后续逐条调 workflow 时优先看这里。 |
| `agent/` | DermAgent 主逻辑 | workflow routing、planner、fusion、evaluation 等核心代码。 |
| `skills/` | skill 实现和注册 | 新增小 skill 时放这里。 |
| `scripts/` | 当前活跃实验脚本 | 保持根目录不移动，避免破坏已有命令引用。 |
| `final-script/` | final round 包装入口 | 保持根目录不移动，主要服务旧 final 实验线。 |
| `final-score/` | final round 分数和导出区 | 结果大包仍按 `.gitignore` 管理。 |
| `outputs/` | 实验输出 | git 忽略，不纳入 GitHub。 |

## 文档目录

| 路径 | 内容 |
|---|---|
| `docs/architecture/` | 系统架构、自进化机制、长篇设计说明。 |
| `docs/experiments/` | 6x6 实验指南、迁移指南、历史结果总结。 |
| `docs/operations/` | 使用规范、当前最佳版本说明、运行手册。 |
| `docs/archive/legacy_iterations/` | v3、v4、v7 等早期迭代文档归档。 |
| `docs/archive/workflow_notes/` | workflow 改进过程中的历史草稿、stage2 笔记。 |

## 目前整理原则

1. 顶层只保留真正高频入口和总览文档。
2. `scripts/`、`final-script/`、`final-score/` 暂时不移动，因为很多命令和文档硬引用这些路径。
3. v3/v4/v7、workflow 改进草稿、旧长文档统一收到 `docs/` 下。
4. 后续新增 6x6 调参结论，优先更新顶层 `6x6工作流状态_20260506.md`。
