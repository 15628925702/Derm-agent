## 🔧 路径配置检查

### 自动路径解析

脚本使用**相对路径**自动解析，无需修改：

```bash
# run_6x6_matrix_parallel.sh 会自动计算
PROJECT_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"

# 数据路径自动基于PROJECT_ROOT
DATASET_DATA_ROOTS=(
  [ham10000]="${PROJECT_ROOT}/data/ham10000"
  [isic2019]="${PROJECT_ROOT}/data/isic2019"
  # ... 等等
)
```

### 模型路径配置

每个模型启动脚本会自动搜索以下路径：

```bash
# 优先级顺序
PREFERRED_MODEL_PATHS=(
  "/models/模型名"           # 优先
  "/root/models/模型名"      # 备选
)
```

**如果模型在其他位置**，有两种方法：

**方法1**: 创建软链接（推荐）
```bash
sudo mkdir -p /models
sudo ln -s /your/path/to/models/* /models/
```

**方法2**: 设置环境变量
```bash
export MODEL_PATH="/your/path/to/Qwen2.5-VL-7B-Instruct"
# 对每个模型分别设置
```

## 📊 实验说明

### 实验矩阵

**6个模型**:
1. Qwen2.5-VL-7B-Instruct (GPU 0, port 8000)
2. Llama-3.2-11B-Vision-Instruct (GPU 1, port 8012)
3. SkinVL-MM (GPU 2, port 8011)
4. Hulu-Med-7B (GPU 3, port 8013)
5. medgemma-4b-it (GPU 0, port 8010) - 第二批
6. DermatoLlama-full (GPU 1, port 8014) - 第二批

**6个数据集**:
1. ham10000 - HAM10000皮肤病变数据集
2. isic2019 - ISIC 2019挑战赛数据集
3. pad20 - PAD-UFES-20数据集
4. scin - SCIN数据集
5. sd198 - SD-198数据集
6. xiangya - 湘雅医院SFT数据

### 运行策略

- **并行度**: 4个GPU，每批运行4个模型
- **第一批**: qwen, llama, skinvl, hulumed (同时运行)
- **第二批**: medgemma, dermatollama (等第一批完成后运行)
- **每个模型**: 顺序处理6个数据集
- **每个数据集**: 30个bootstrap cases + 30个compare cases

### 预计时间

- 单个case: 约30-120秒
- 单个数据集(60 cases): 约30分钟-2小时
- 单个模型(6个数据集): 约3-12小时
- **完整6x6实验**: 约18-36小时

## 🔍 常见问题

### 1. 模型路径找不到

**症状**: 启动脚本报错 "Model not found"

**解决**:
```bash
# 检查模型是否存在
ls -lh /models/
ls -lh /root/models/

# 创建软链接
sudo ln -s /your/models/path /models
```

### 2. 端口被占用

**症状**: "Port already in use"

**解决**:
```bash
# 查找占用端口的进程
netstat -ltnp | grep :8000

# 杀死进程
kill -9 <PID>
```

### 3. GPU内存不足

**症状**: CUDA out of memory

**解决**:
```bash
# 调整GPU内存利用率
export GPU_MEMORY_UTILIZATION=0.7

# 或修改启动脚本中的参数
```

### 4. 数据集路径错误

**症状**: "Dataset not found"

**解决**:
```bash
# 检查数据集完整性
ls -lh /path/to/DermAgent/data/

# 确保xiangya数据集解压
cd /path/to/DermAgent/data/
unzip sft数据.zip  # 如果还是压缩包
```

### 5. Conda环境问题

**症状**: Import错误

**解决**:
```bash
# 重新创建环境
conda env remove -n derm-qwen
conda env create -f environment.yml

# 或手动安装缺失的包
conda activate derm-qwen
pip install <missing-package>
```

## 🎯 总结

### 最简迁移流程

```bash
# 1. 在源机器打包
cd /root
tar czf dermagent.tar.gz DermAgent/ --exclude='DermAgent/outputs'
tar czf models.tar.gz models/

# 2. 传输到新机器
scp dermagent.tar.gz models.tar.gz user@new-machine:/path/to/

# 3. 在新机器解压
cd /path/to/
tar xzf dermagent.tar.gz
sudo mkdir -p /models
sudo tar xzf models.tar.gz -C /

# 4. 配置环境
cd DermAgent
conda env create -f environment.yml
conda activate derm-qwen

# 5. 运行实验
bash scripts/run_6x6_matrix_parallel.sh
```

### 关键点

✅ **无需修改代码** - 脚本使用相对路径，自动适配  
✅ **模型路径灵活** - 支持多个搜索路径  
✅ **数据集自包含** - 全部在DermAgent/data目录  
✅ **环境可复现** - environment.yml包含所有依赖  

⚠️ **注意事项**:
- 确保4个GPU可用
- 确保足够的磁盘空间（至少500GB）
- 建议使用后台运行（nohup）
- 定期检查日志和进度
